Двойной клик — редактировать
Как работать: двойной клик по блоку — название, даты, цвет и ресурс. Тяните блок за середину, края — для изменения длительности. Двойной клик по пустой строке добавляет блок. Метки можно двигать за линию, редактировать — по подписи.
Названия ресурсов, заголовок, описание, названия кварталов и месяцев редактируются прямо на странице. Изменения сохраняются в этом браузере. Для переноса и надёжного хранения скачайте HTML с актуальным планом. Точные дни восстановлены по картинке приблизительно; задачи справа от марта сохранены за пределами периода.

Все задачи

Задачи вне выбранного периода тоже сохранены. Измените период, чтобы увидеть их на ганте.
